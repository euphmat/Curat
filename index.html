YouTube API 設定

静的サイトからプレイリストを取得するため、YouTube Data API v3 の API キーをこの端末に保存します。

安全に使うための設定

Google Cloud Console で YouTube Data API v3 を有効化し、キーの「ウェブサイトの制限」に公開予定の GitHub Pages URL を登録してください。

Cloud Console

データの保存と復元

進捗は自動でブラウザに保存されます。保存ファイルを接続すると、サイトデータを消してもファイルから復元できます。

ブラウザ保存は有効です

外部の保存ファイルはまだ接続されていません。

保存ルール
  1. 操作のたびにブラウザへ自動保存
  2. 接続中の保存ファイルへも自動で上書き
  3. API キーだけは安全のためファイルに含めない

プレイリストを管理

同じゲームタイトルを指定したプレイリストは、サイドバーの同じフォルダーにまとまります。

自動分類ルール

次回以降、プレイリスト名に正式名またはいずれかの別名が含まれていれば、同じゲームのフォルダーへ自動でまとめます。

新しいフォルダー

ゲームごとのフォルダーを作り、複数の実況プレイリストをひとまとめにできます。

フォルダーアイコン
標準のフォルダー 内蔵アイコン、またはIconifyのSVGから選べます。
