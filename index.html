実況ライブラリ

FOR YOUR LIBRARY

おすすめプレイリスト

登録済みプレイリストを手がかりにYouTube全体から探し、ゲームと投稿者の登録状況を4つの組み合わせで整理します。視聴状況は使用しません。

設定と保存データ

YouTube API 設定

静的サイトからプレイリストを取得するため、YouTube Data API v3 の API キーを使用します。

安全に使うための設定

Google Cloud Console で YouTube Data API v3 を有効化し、キーの「ウェブサイトの制限」に公開予定の GitHub Pages URL を登録してください。

Cloud Console

クラウド同期

ログインすると、進捗を Firebase に保存し、iPad とパソコンの間でも自動同期します。

Firebase へ接続中

接続後に Firebase のデータを読み込みます。

クラウド同期の初期設定が必要です

firebase-config.js を設定して GitHub Pages へ反映してください。詳しい手順は Readme にあります。

ログイン中
ユーザー名とパスワードは、このブラウザ内に保存されます。

手動バックアップ

保存ルール
  1. ログイン中の変更は Firebase へ自動保存
  2. ログアウト中の変更はページを閉じると失われます
  3. API キーとログイン情報はこのブラウザだけに保存し、バックアップには含めません

プレイリストを管理

同じゲームタイトルを指定したプレイリストは、サイドバーの同じフォルダーにまとまります。

自動分類ルール

次回以降、プレイリスト名に正式名またはいずれかの別名が含まれていれば、同じゲームのフォルダーへ自動でまとめます。

ライブラリを整理

新しいフォルダー

ゲームごとのフォルダーを作り、複数の実況プレイリストをひとまとめにできます。

アイコンは作成後に選べます

フォルダーを作成したあと、操作メニューの「アイコンを変更」から絵文字を設定できます。iPad ではフォルダーを長押しして開けます。
フォルダー情報

フォルダー名を変更

中にあるプレイリストは、新しいフォルダー名へまとめて移動します。

入力に近い候補 クリック、または ↑↓ キーで選択

フォルダーアイコンを変更

フォルダーを見分けやすい絵文字に変更できます。

選択中のアイコン
標準のフォルダー カラーアイコン、またはIconifyのカラーSVGから選べます。
最近使った絵文字 よく使うアイコンをすぐ選べます
